Caspian Server Backup

Утилита предназначена для ежедневного создания резервных копий Linux-сервера одного владельца, их проверки и хранения зашифрованного архива в его Google Drive.

  • Данные архива шифруются на сервере до загрузки в Google Drive.
  • Google-доступ ограничен разрешением drive.file и файлами резервной копии, которыми управляет эта утилита.
  • Старая проверенная копия сохраняется, если новая не прошла проверку. После успешной проверки остаётся одна актуальная копия.

Утилита предназначена только для личного восстановления сервера. Она не принимает данные других пользователей и не предоставляет публичные услуги резервного копирования.
